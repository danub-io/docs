title: "Turbo Code OLD — Multi-Agent Terminal AI Assistant"
---

Multi-agent terminal AI assistant with a web interface. Four specialized modes (Debug, Plan, Code, Ask) for interacting with LLMs via OpenAI-compatible API.

**Stack:** Node.js + Express + WebSocket (backend) · React + Vite + shadcn/ui (frontend)

## Features

- **Multi-Agent Architecture**: Four modes (Debug, Plan, Code, Ask) for different types of interaction
- **Autonomous Execution**: CodeAgent executes plans, bash, edits files with circuit breaker
- **Security**: Process group isolation, 38 blocked command patterns, 12 destructive patterns requiring confirmation, 3-strike circuit breaker
- **Persistent Memory**: `/memory`, `/forget`, `/dream` — auto-dream consolidates memories in background, FTS5 full-text search, RAG injection
- **RAG Injection**: Relevant memories injected into the system prompt (Prefix Caching-aware)
- **Streaming**: Token-by-token responses via WebSocket with events for tokens, reasoning, tool calls, config changes, terminal output, and more
- **17 Built-in Tools**: bash, read, write, edit, grep, find, ls, fetch, ask_user, add_to_context, project_inspector, update_task_progress, run_background, git, rollback, pr, review + skills (skill_shadcn, skill_review-pr)
- **MCP Support**: Model Context Protocol for external tool servers
- **Skills System**: Reusable, domain-specific capabilities (shadcn/ui reference, PR review)
- **Fuzzy Edit**: Edit tool with fuzzy block matching and inline diff output
- **Shadcn/ui**: Dark theme, modals, session sidebar, settings dialog
- **Terminal**: Background process engine via node-pty (no frontend UI)
- **Settings Dialog**: Runtime model/provider/API key configuration
- **Self-Evolution Engine**: Auto-commit improvements, PR creation & auto-merge via PRBuilder + AutoMergeGate
- **Hierarchical Swarm**: Multi-agent task decomposition with supervisor orchestration
- **Error Reports**: Automated error reporting with component health tracking and suggestions
- **Emergency Mode**: Automatic recovery with self-healing, connection watchdog, and factory reset

## Quick Start

```bash
# The default branch is gemini (public/Gemini-optimized).
# For development, switch to the full branch:
git clone https://github.com/danub-io/turbo-code.git
git checkout develop
cd turbo-code

# Configure API key (server auto-creates .env from .env.example if missing)
cp .env.example .env
# Edit .env with your API key

# Quick setup (installs all deps + builds)
npm run setup

# Or manually:
npm install && cd web && npm install && cd ..
npm run build

# Run
npm run dev
# Open http://localhost:3001 (default port, overridable via PORT env)
```

## Stack

| Layer | Technology |
|--------|-----------|
| Backend | Node.js + Express + WebSocket + TypeScript |
| LLM Client | OpenAI-compatible (DeepSeek, OpenAI, Anthropic, Gemini, OpenRouter) |
| Frontend | React + Vite + TypeScript + shadcn/ui + Tailwind + xterm.js |
| Storage | SQLite (`~/.config/turbo/data.db`) with WAL mode, 64MB journal limit, FTS5 full-text search, auto-backup on shutdown, health API |
| Tests | Vitest |
