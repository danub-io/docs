## Overview

Static blog (SSG) built with Astro 6 and React 19, hosted on GitHub Pages.

```
Markdown (MD) → Content Collections → Astro Pages → Static HTML → GitHub Pages
```

### Stack

| Technology                  | Role                     |
| --------------------------- | ------------------------ |
| **Astro 6**                 | SSG Framework            |
| **React 19**                | Interactive components   |
| **Tailwind CSS v4**         | Styling + Typography     |
| **@base-ui/react**          | Accessible UI primitives |
| **@tailwindcss/typography** | Prose styling            |
| **@tailwindcss/vite**       | Tailwind Vite plugin     |
| **Content Collections**     | Content management       |
| **date-fns**                | pt-BR date formatting    |
| **lucide-react**            | Icons                    |
| **react-markdown**          | MD rendering in React    |
| **sharp**                   | Image processing         |
| **GitHub Pages**            | Hosting with global CDN  |

## Content Structure

```
src/content/
├── posts/          # MD articles with frontmatter
├── authors/        # Author profiles
└── pages/          # Static pages
```

Posts have a schema with `title`, `description`, `date`, `authors`, `tags`, `image`.

## Getting Started

```bash
git clone <repo-url>
cd gospelreads
pnpm install
pnpm dev          # Local server (localhost:4321)
```

### Build and Deploy

```bash
pnpm build        # Generates dist/
# Deployment is automatic via GitHub Actions on push to main
# Manual deploy: push to main branch, or use workflow_dispatch
```

## Performance

- 100/100 Lighthouse performance
- Pure SSG with no JavaScript on initial load
- 1-year cache for static assets
- Optimized images with CSS filters
