## Historical Overview

Flow was a **dual-purpose project** during development:

1. **Visual Pipeline Builder (Abandoned)** — A React frontend for designing agent pipelines visually using nodes and edges (React Flow). Replaced by the Turbo TUI.
2. **Runtime Resources (Absorbed into Turbo)** — System prompts, AI skills (22 total), and agent configurations now live directly in `/home/dan/Documentos/turbo/agents/` and `/home/dan/Documentos/turbo/skills/`

The Flow source directory (`/home/dan/Documentos/flow/`) has been removed from disk. This documentation page is maintained for **historical reference only**.

Flow's directory structure (for historical reference):

```
flow/
├── agents/             # System prompts — now in turbo/agents/
├── skills/             # AI skills — now in turbo/skills/
├── public/             # Model provider reference — now in turbo/public/
├── src/                # React application (abandoned)
└── saves/              # YAML backups (archived)
```
