# Turbo Postmortems

Postmortems for bugs, architectural decisions, and debugging sessions in the Turbo project are stored at:

- **Knowledge directory:** [`/home/dan/Documentos/turbo/knowledge/`](https://github.com/danub-io/turbo/tree/production/knowledge)

## Creating a New Postmortem

1. Create a new file at `knowledge/postmortem-<slug>.md` in the Turbo repository
2. Use the format: `# Postmortem: <Descriptive Title>`
3. Include: problem description, root cause, fix applied, lessons learned
4. Commit with message `docs: add postmortem for <issue>`

## Existing Postmortems

See the [`knowledge/`](https://github.com/danub-io/turbo/tree/production/knowledge) directory for existing postmortems.
