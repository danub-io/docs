Welcome to the **Turbo** documentation — an agent ecosystem orchestrator. Turbo provides a squad of specialized LLM agents that decompose complex tasks, plan execution, and deliver results autonomously — no human-in-the-loop.

---

## Overview

Turbo operates on a **TUI → Director → Agent Pipeline** model:

1. **TUI** (turbo-tui) — full-screen terminal with 4 modes (Director, Manager, Planner, Executor) + pipeline sidebar
2. **Director** (single point of contact) — persistent brain with memory, converses in pt-BR, refines scope, loads mode overlays (`/critic` or `/smart`)
3. **Manager** — decomposes complex tasks into discipline-based work packages (quality, security, docs, etc.)
4. **Planner** — creates structured execution plans with serial/parallel task optimization
5. **Executor** — executes plan tasks with git safety, retry logic, and atomic rollback
6. **Draw** — generates Unicode box-drawing diagrams from natural language descriptions

## Philosophy

All agents operate under the **Autonomous Execution Mandate**:

- Agents do **not** assist — they **do**
- No human reads, reviews, or touches the output
- Submission is FINAL — no second chance, no handoff
- False completion is worse than failure
- Agents have no eyes or ears — verification is programmatic

## CLI Commands

| Command              | Source                    | Description                                                                                             |
| -------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------- |
| `turbo`              | `turbo.tui:main`          | Full-screen TUI (4 modes: Director, Manager, Planner, Executor)                                         |
| `manager "prompt"`   | `turbo.cli:manager_main`  | Decompose complex task into discipline-based demands. Flags: `-q` (query), `-a` (audit), `-m` (monitor) |
| `planner "desc"`     | `turbo.cli:planner_main`  | Generate structured execution plan. Flags: `-q`, `-a`, `--plan-id-prefix`, `--demand-id`                |
| `executor <plan-id>` | `turbo.cli:executor_main` | Execute existing plan. Flags: `-a`, `--plan-dir`, `--max-retries`                                       |
| `draw "prompt"`      | `turbo.cli:draw_main`     | Generate Unicode box-drawing diagram                                                                    |
| `turbo plan "desc"`  | `turbo.cli:main`          | Plan + execute in one step (legacy)                                                                     |
| `turbo exec <id>`    | `turbo.cli:cmd_exec`      | Execute existing plan (legacy)                                                                          |
| `turbo status <id>`  | `turbo.cli:cmd_status`    | Show plan execution status                                                                              |
| `turbo list`         | `turbo.cli:cmd_list`      | List available plans                                                                                    |

## System Prompts

Agent instructions live across `agents/`:

| File                                     | Role                                                                  |
| ---------------------------------------- | --------------------------------------------------------------------- |
| `agents/director/AGENTS.md`              | Base director prompt (always active)                                  |
| `agents/director/modes/smart.md`         | Intelligent/proactive overlay (`/smart`)                              |
| `agents/director/modes/critic.md`        | Critical/restrained overlay (`/critic`)                               |
| `agents/director/modes/work-template.md` | Work output template                                                  |
| `agents/director/memory/`                | 10 topic files (architecture, decisions, postmortems, patterns, etc.) |
| `agents/director/index.yaml`             | Memory index (~0.5K tokens)                                           |
| `agents/manager/prompt.md`               | Task decomposition instructions                                       |
| `agents/planner/prompt.md`               | Execution plan generation instructions                                |
| `agents/executor/prompt.md`              | Task execution instructions                                           |
| `agents/draw/prompt.md`                  | Diagram generation instructions                                       |

Each agent prompt follows canonical sections: Autonomous Execution Mandate (C0), Core Objective, Absolute Constraints, Serial vs. Parallel, Output Format, Verification.
