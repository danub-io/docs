Welcome to the **Turbo** documentation — an agent ecosystem orchestrator. Turbo provides a squad of specialized LLM agents that decompose complex tasks, plan execution, and deliver results autonomously — no human-in-the-loop.

---

## Overview

Turbo operates on a **Director → Agent Pipeline** model:

1. **Director** (single point of contact) — converses with the user, refines scope, loads mode overlays (`/critic` or `/smart`)
2. **Manager** — decomposes tasks into discipline-based work packages
3. **Planner** — creates structured execution plans (serial/parallel tasks)
4. **Executor** — executes plan tasks with git safety and rollback
5. **Draw** — generates Unicode box-drawing diagrams

```
User → Director (AGENTS.md + modes/{critic,smart})
         │
         ├── Direct execution (edit/write/bash)
         └── Delegated pipeline:
               Manager → Planner → Executor
```

## Philosophy

All agents operate under the **Autonomous Execution Mandate**:

- Agents do **not** assist — they **do**
- No human reads, reviews, or touches the output
- Submission is FINAL — no second chance, no handoff
- False completion is worse than failure
- Agents have no eyes or ears — verification is programmatic

## CLI Commands

| Command | Source | Description |
|---------|--------|-------------|
| `turbo` | `turbo.tui:main` | Full-screen TUI (Director, Manager, Planner, Executor modes) |
| `manager "prompt"` | `turbo.cli:manager_main` | Decompose a task into discipline-based work packages |
| `planner <demand-id>` | `turbo.cli:planner_main` | Create execution plan from a demand |
| `executor <plan-id>` | `turbo.cli:executor_main` | Execute a plan's tasks |
| `draw "prompt"` | `turbo.cli:draw_main` | Generate a Unicode box-drawing diagram |

## System Prompts

All agent instructions live in `agents/director/`:

| File | Role |
|------|------|
| `AGENTS.md` | Base director prompt (always active) |
| `modes/smart.md` | Intelligent/proactive overlay (`/smart`) |
| `modes/critic.md` | Critical/restrained overlay (`/critic`) |
| `modes/manager.md` | Task decomposition instructions |
| `modes/planner.md` | Execution plan instructions |
| `modes/executor.md` | Task execution instructions |
| `modes/draw.md` | Diagram generation instructions |

Each mode follows canonical sections: Autonomous Mandate (C0), Role, Principles, Constraints, Workflow, Output, Self-Verification, Anti-Patterns.
