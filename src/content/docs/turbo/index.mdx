Welcome to the **Turbo** documentation — an AI Agent Orchestrator that breaks complex software tasks into structured plans and executes them autonomously through the [pi coding agent](https://github.com/earendil-works/pi-coding-agent).

---

## Overview

Turbo takes a single high-level prompt and:

1. **Plans** — Decomposes the prompt into ordered, isolated tasks via an AI model
2. **Executes** — Runs each task through the pi coding agent with live progress tracking
3. **Reports** — Shows per-task status, token usage, and dollar costs

```
prompt → [Planner] → plan.yaml + tasks/*.md → [Executor] → completed tasks
```

## CLI Commands

The `turbo` command has been replaced by three separate commands:

| Command | Description |
|---------|-------------|
| `planner [-a] "prompt"` | Plan + auto-execute (no confirmation). `-a` opens visible terminal windows |
| `executor [-a] <plan_id>` | Execute an existing plan. `-a` opens visible terminal windows |
| `diagrammer "prompt"` | Generate an ASCII diagram from a description |

## Quick Start

```bash
# Set up provider key
export OPENCODE_API_KEY=sk-your-key-here

# Run a full plan
planner "Build a CLI tool that reads CSV files and exports JSON"

# Or plan first, then execute separately
planner "Refactor authentication to use JWT"
executor <plan_id>
```

## Relationship with Flow

Turbo is the **execution engine**. It reads system prompts and skills from the [Flow](/docs/flow/) project (the `agents/` directory), and generates plans in YAML/Markdown format. Flow is a visual pipeline builder that can eventually orchestrate Turbo via file-based communication.
